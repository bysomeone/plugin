# RGB 桥运维手册

适用：chain33 主链上的 `rgbx` 跨链桥（XBTC / RGB20），以及配套的 RGB 网关、TSS 签名节点与侧车。
配置项的逐项说明见
[CONFIG.md](../../plugin/dapp/lightclient/rpc/lightclient/neutrino/CONFIG.md)；本手册只讲**怎么部署、
怎么值守、出问题怎么办**，并按主题拆成子文档。

## 1. 部署拓扑与信任边界

```
用户钱包/前端 ──HTTPS──> 网关（唯一公网入口）
                            │  ▲
                 入站? 否    │  │ 桥主动出站长连接（SSE/轮询）
                            ▼  │
                    TSS 节点 para1..N（桥 + 侧车）──> chain33 主链（rgbx）
                            │
                            └──> BTC 节点（SPV / btcd）
```

硬约束：

- **桥不监听任何入站端口**。除 E2E 的 `testListen`（生产必须为空）外，桥只主动连出。
- 网关是唯一公网入口；对用户暴露标准 RGB HTTP JSON-RPC 与充值请求 API，对桥暴露 `/bridge/*`（bearer，
  可选 mTLS）。
- 签名节点（para2..N）互相通过 libp2p 通信，必需预共享密钥（PSK），并配固定 `peers/threshold/rank`。
- 主链 RPC 只对网关/运维网络开放；BTC 节点 RPC 只对桥开放。

## 2. 上线前确认清单

按顺序过一遍，任一项未完成不要切生产流量：

- [ ] 生产值与测试开关核对完毕，见 [02-1-部署与配置.md](02-1-部署与配置.md)。
- [ ] 主链、BTC 节点、TSS 节点、侧车、网关按顺序部署，见 [02-1-部署与配置.md](02-1-部署与配置.md)。
- [ ] 治理初始配置（限额、暂停开关、RGB20 提现手续费）已生效，见
      [02-5-治理与日常操作.md](02-5-治理与日常操作.md)。
- [ ] 冷备已实际跑通，恢复演练通过，见 [02-2-备份与恢复.md](02-2-备份与恢复.md)。
- [ ] `/healthz`、启动自检、日志关键字与事件账本已接入监控，见
      [02-3-监控与告警.md](02-3-监控与告警.md)。
- [ ] 应急预案已与值班确认，见 [02-4-应急预案.md](02-4-应急预案.md)。
